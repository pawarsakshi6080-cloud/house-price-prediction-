# House Price Prediction

A Machine Learning project to predict house prices using the Kaggle House Prices dataset.

## 🚧 Project Status

Project in Progress

## 📂 Dataset

- House Prices: Advanced Regression Techniques (Kaggle)

## 🎯 Goal

Build and compare multiple regression models to accurately predict house prices through data preprocessing, feature engineering, model training, evaluation, and hyperparameter tuning.

## 🛠 Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
